# Tallow & Care — Official Landing Page

A modern, responsive landing page for **Tallow & Care**, a sustainable startup creating eco-friendly, vet-safe soaps, shampoos, and skincare products for animals using upcycled chicken and mutton tallow, with parallel human-grade variants made from pure ghee.

---

## 🚀 Live Demo
https://tallow-and-care-official.vercel.app/

## ✨ Features
- Fully responsive modern UI
- Premium visual branding and hero video support
- Social media integration (Instagram, LinkedIn, WhatsApp)
- Clean animations with optimized loading
- SEO-optimized meta tags and social preview cards
- Organized and scalable project structure
